# SearchServiceSpec
Proyecto de aplicación web que le permite a los usuarios _scrappear_ sitios web de forma automatizada y controlada, sin necesidad de que ellos tengan que hacerlo.
Este proyecto se concibe dentro de la práctica de la materia [Ingeniería de Aplicaciones Web](https://www.info.unlp.edu.ar/wp-content/uploads/2026/06/Ingenieria-de-Aplicaciones-Web.pdf) de la **Facultad de Informática de la UNLP**.
<br>
<br>
Este proyecto utiliza las siguientes tecnologías:
- React + Vite (Frontend)
- Nest.js (Backend)
- MongoDB (Base de Datos)
